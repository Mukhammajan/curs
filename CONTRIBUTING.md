# Contributing Guidelines

Все вклады, отчеты об ошибках, исправления ошибок, улучшения документации, улучшения и идеи приветствуются.

## How to Contribute
1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear message.
5. Submit a pull request.

## Bug Reports
Describe the problem clearly and provide steps to reproduce it.

## Bug Fixes and Improvements
Explain what you changed and why the change is useful.

Thank you for contributing!
